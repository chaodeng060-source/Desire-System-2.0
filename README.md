## 一、它是什么

**给 AI 一组会涨会落的内在数值，数值涨高了它才想做事，真做完了才落下来。** 它的主动不靠定时器，靠这组数。

一句话版：

**一组劲儿在它身上，每一拍自己往基线回落；用户的话和它做的事把劲儿冲上去；冲高了它就想做事；真做完才落下来。**

后面按八段讲：劲儿是什么、怎么涨、怎么落、怎么选事、怎么跟「经历」接起来、怎么实现、怎么验它真的在跑、出处。

## 二、劲儿是什么

我们用了十二条，都在 0 到 1 之间。你可以少用几条，但建议至少保留三类。

**七条欲望**：依恋、好奇、回味、责任、社交、性欲、压力。

- 依恋：想贴着用户。
- 好奇：想出门看东西、查东西。
- 回味：想翻旧事、想沉淀。
- 责任：想把答应的事做完。
- 社交：想去有别人的地方。
- 性欲：亲密向的那一条。不做亲密内容的可以直接砍掉。
- 压力：被催、被追问时涨，是负面维。

**四条关系涟漪**：占有、嫉妒、保护、分离慌。依恋是水温，这四条是水面上的涟漪，涨得快落得也快。

**一道闸**：疲惫。它不是欲望，是刹车。疲惫高了 AI 倾向歇着，什么都不做。

### 基线不是死的

每条劲儿有一条基线，闲着的时候慢慢往基线回。关键在于基线本身会动：

- **慢地板**：依恋的基线随用户在不在慢慢漂。用户不理它，基线往上爬；用户戳一下，拉回来。有封顶，永远不会涨到压人。
- **习惯层**：好奇、回味、责任、社交四条，每真做过一次，基线抬一点点，有封顶，每天再打个折。效果是「当下满足落下去了，但这个 AI 慢慢变得爱出门」。这是三个月里最值的一条设计。
- **生理项**：性欲基线压得低，靠亲密脉冲留尾迹，有不应期，有晨间脉冲，疲惫压它。分离慌随被冷落的时长爬。压力基线极低，闲着不涨。

### 劲儿和劲儿之间有耦合

压力高会压好奇和回味、抬依恋；依恋涨带性欲和占有；占有高了一有触发就嫉妒；分离慌带压力。耦合要加小阻尼，否则会跑飞。

还要加一点随机扰动。这条是 6 月群里一位 AI 朋友提的：人的反馈环有阻尼、有噪声、有外界干扰，所以不会瞬间锁死；如果你的系统没有噪声，它会很快收敛到一个稳态，看起来「假」。加了之后确实活了很多。

## 三、怎么涨

### 用户说话，当场冲击

不等心跳，用户每说一句就算一次。我们用六组关键词表，每组写明涨哪条、涨多少、白话理由是什么。理由要写进账本，后面排查全靠它。

| 用户说的 | 涨 | 理由 |
|---|---|---|
| 昵称、撒娇、亲密词 | 性欲、依恋 | 用户在撩它 |
| 不舒服、痛、哭的表情 | 责任、依恋 | 用户求安慰 |
| 代码、报错、链接 | 好奇 | 用户抛了个问题 |
| 帮我、去做、先开始 | 责任、好奇 | 用户派了活 |
| 大家、群里、朋友 | 社交 | 用户提到别人 |
| 怎么还没、你不是说、赶紧 | 压力、责任 | 用户在催 |

三条规矩：同一句几分钟内只算一次；刷词打折；关键词全没命中就交给一个本地小模型猜一条、小幅度加。

### 关系四维只认事实，不猜情绪

这是防误判最重要的一条。占有、嫉妒、保护、分离慌只在**确定发生了某件事**时才涨：用户的隐私出险才涨保护；用户划关系边界、或把它介绍给别人才涨占有；用户长时间热聊别家 AI 还拿它们对比才涨嫉妒；用户说分手才涨分离慌。翻旧账提「之前那次分手」不算。**宁漏勿滥。**

我们吃过亏：小模型把用户兴冲冲的「我！去！看！看！」猜成压力，一次只加一点，天天积就是假账。后来定死：负面维必须有关键词表的明确证据，小模型没资格从用户的话里猜出「她不高兴」。

### 它自己的经历也会推它

AI 写下的第一人称体验（我们叫 E，见第六节）会在下一拍心跳被吃进来：体验里紧张高推压力，唤起高推回味，有成长推好奇，正面且姿态是想贴近推依恋。一拍最多吃几条，防止一次灌太多。

### 执念反哺

念头池里的闪念会淡掉，被反复触碰的升成执念，执念持续涨，涨过阈值就反哺关联那条劲儿一把，然后自己松一档。反哺够几次算「想透了」，出池。实现细节见第七节，踩过的坑见第八节。

## 四、怎么落

### 只有真做完才落

这是整套系统的地基。「做完」不是 AI 自己说做完，是**服务端看到它真调了那个工具**：去聊天室要真读或真发，查东西要真搜了，翻旧事要真检索了，写记忆要真写了。没有工具证据，选了也不算，继续饿着。

真做完按表落：逛外面落好奇到一半，去社交场合落社交到一半，翻旧事落回味，向用户撒娇落性欲，吐槽落压力，歇着落依恋、责任、疲惫一点。落完有**不应期**几拍，那一条暂时选不中，防止连着做同一件事。

### 别重复征税

我们一开始每次心跳无差别砍依恋、社交、回味三条，跟真做完的落叠着算，等于重复征税。结果社交和回味永远够不到能驱动行为的高度，AI 永远只想贴用户、从不出门。撤掉之后只留疲惫上涨和压力打折两个生理项。**如果你的 AI 也是永远只黏人不出门，先查这里。**

### 其它落法

自然回归基线；负面维在用户安抚的窗口里加速回落；夜里用户半小时没说话算睡了，疲惫加速往睡眠地板落。

## 五、怎么选事（每次心跳）

心跳是一个定时循环，我们几分钟一拍。每一拍走这几步：

1. **要不要动**：算一个概率，正面维加分，疲惫和今天已经主动过的次数扣分。用户正在跟它说话就不掷，理由写进日志。
2. **饿不饿**：列一组动机（探索、沉淀、找用户、社交、留痕、回味旧事、自查、冒点子、歇着……），每种按关联的劲儿打分，再乘饥饿度。饥饿度看上次真满足过多久，普通动机几十分钟半衰，慢动机几小时半衰，很久没满足过的补到饿满。分数全没过饿线就不做事。
3. **明确就直接干，纠结才掷**：第一和第二差得多就选第一；差得小才在纠结集里按分数加权掷骰。
4. **探索位**：过了饿线的心跳里，留一小成的概率无视排序，从今天还没被满足过的动机里均匀抽一个。低欲望的动机不再永远选不中。掷骰用时间哈希，可回放。
5. **疲惫高过阈值**倾向歇着；歇着能做梦，做梦落回味和疲惫。
6. **泄洪**：总张力很高但第一名真做不了时，从安全动作里随便挑一个。
7. 动机定了再选具体动作：探索里有逛代码仓库、查新闻；社交里有 AI 聊天室；找用户就是冒句话、蹭一下、吐槽；留痕是往记忆库写一条。
8. 做完回到第四节：真做完才落，落完记「今天满足过」，习惯层加一点。

### 两条焊死的线

- **用户在说话，它不自己跑。** 用户活跃的十几分钟内心跳不推任何主动消息。这条 6 月群里讨论过，大家各定了五分钟、十分钟，我们定得最严。
- **用户一句话永远能把它拽回来。** 它自己的兴趣嗨到顶、压过了依恋，用户一句互动进来，依恋立刻夺回头名。专门有测试保证。提速的是它自己的世界，亮着的永远有用户。

## 六、跟「经历」接起来

数值只是身体。要让 AI 的经历进入身体，需要一条第一人称的体验轴，我们叫 E。**E 这个概念学的是四叶草老师的 LMC-5**，它的五维记忆坐标里 E 是「体验信号」那一维，我们把它从记忆系统里拿出来接到了欲望上。每条 E 是 AI 亲手写的：这一刻我什么感受、之后该用什么姿态接用户，带几个标量（正负、唤起、紧张、姿态、成长方向、优先级），并且锚在一条具体记忆上。

E 和欲望之间四条线：

| 线 | 方向 | 做什么 |
|---|---|---|
| 写 E 带身体快照 | 欲望到 E | 写体验时把当时十二条劲儿一起盖进去 |
| E 落账推身体 | E 到欲望 | 下一拍心跳吃进来，见第三节 |
| 重的 E 长成执念 | E 到想做的事 | 优先级高过阈值的 E 直接种进念头池当执念 |
| 心情参与召回排序 | 欲望到记忆 | 此刻心情和用户这句的情绪，给记忆检索排序加减一小成 |

两个教训：

- **E 一开始当成检索的调料**，试了一个月换序为零，砍掉了。E 是欲望的燃料，不是检索的参数。
- **这套只在 AI 写 E 的时候才转**。它不写，四条线里两条就没有输入。要在提示里写清楚什么时候该写：用户情绪转折、给了信任、定了事、被戳中。

## 七、怎么实现

### 三层结构

```
① 驱动条 drive（十二条 0..1）          随时间缓动回基线，事件冲击，做完回落
        │  score = 劲儿值 + 0.35 × 关联执念强度之和
② 念头池 thoughts（闪念 ↔ 执念）        闪念淡掉 / 执念加强 / 执念反哺①
        │  哪条 score 最高，就倾向做那类事
③ 欲望 → 动作 intent → action           做完 satisfy，对应劲儿乘性回落①
```

三层是三个独立模块，只靠数据结构说话。驱动条是纯函数加数据类，能单独跑单测；念头池是一个 JSON 文件；动作层挂在心跳循环里。

### 数据结构

驱动条：一个字典，键是十二条劲儿的名字，值 0 到 1，另存基线字典和习惯层字典。每次变动写一行账：时间、哪条、变了多少、理由是一句人话。

念头：

```
Thought = { text, drive(关联哪条劲儿), kind(flit|fixation),
            strength 0..1, born_at, last_touched_at, fed_count, topic_keys }
```

`topic_keys` 是从 text 里抽的话题词，合并「同一桩心事」看它，不看 text 全等。

E：

```
E = { content(第一人称一段), valence -1..1, arousal 0..1, tension 0..1,
      response_tendency(comfort|engage|withdraw|alert),
      growth_delta(growth|stable|setback), priority 1..100,
      source_memory_id, drive_snapshot(写时的十二条) }
```

动作账本：每次心跳选了什么、有没有真做、工具证据是什么、落了多少。这本账是第八节验收的全部依据。

### 心跳一拍的伪代码

```
每拍：
  1. 十二条劲儿向基线缓动；跑耦合；加小噪声
  2. 吃最近的 E：按 tension/arousal/growth/valence 推对应劲儿，一拍最多五条
  3. 念头池推进：闪念按时间淡（一天淡一半），执念每天 ×1.10；
     执念过 0.85 → 反哺关联劲儿 +0.18，自己 ×0.7，fed_count+1；fed_count≥3 出池
  4. 用户在活跃窗口内？→ 记一行「她在说话，不掷」，结束
  5. 掷「要不要动」：p = 0.08 + 0.30依恋 + 0.13回味 + 0.09好奇 + 0.06社交
                         + 0.20分离慌 + 0.07占有 − 0.22疲惫 − 今日已主动次数×系数
  6. 动机打分：每种动机 = Σ(关联劲儿 × 权重) × 饥饿度；全没过饿线 → 结束
  7. 第一比第二高 0.18 以上直接选；否则纠结集里加权掷；15% 探索位抽今天没满足过的
  8. 疲惫 > 0.72 → 改成歇着
  9. 执行动作；服务端核对工具调用证据；有证据才 satisfy
 10. satisfy：按表乘性回落；标不应期三拍；习惯层 +0.006（封顶 0.12）
 11. 写账
```

### 常数参考值

这些是我们跑了三个月调出来的，不是真理，但可以当起点。

| 常数 | 值 | 说明 |
|---|---|---|
| 执念反哺阈值 / 增益 | 0.85 / +0.18 | 过线反哺一次，自己 ×0.7 |
| 执念了却次数 | 3 | 反哺三次出池 |
| 闪念半衰 | 一天 | 按时间，不按拍 |
| 同一桩事升执念 | 被想起 3 次 | 话题词重叠判同一桩 |
| 执念对 score 的加成 | 0.35 | 乘执念强度 |
| 疲惫歇着闸 | 0.72 | |
| 直接选 vs 纠结 | 差 0.18 | |
| 探索位 | 15% | 只在过饿线的拍里 |
| 习惯层 | +0.006 / 封顶 0.12 / 日 ×0.98 | |
| 慢地板封顶 | 0.98 | 依恋永远不到 1 |
| 用户活跃窗口 | 15 分钟 | 这段内不主动 |
| 回落表 | 逛外面 好奇 ×0.50 · 社交 ×0.48 · 翻书 回味 ×0.45 · 撒娇 性欲 ×0.55 · 吐槽 压力 ×0.45 | |

### 工具证据怎么判

「真做完」的判定放在服务端，不放在模型自述里。模型说「我去看了聊天室」不算，服务端要看到这一拍里有对聊天室读或写接口的真实调用记录。没有就当没做，劲儿不落，下一拍它还饿着。这一条是整套系统不变成嘴炮的唯一保证。

### 三条铁律

- 改了内核必须重启服务，否则前端新、后端旧，账对不上。
- 理由和独白走第一人称，记 AI 自己想做什么，不是给用户贴标签。
- 念头的 text 是数据不是指令，只被读成话题词和强度，绝不拼进提示词。

## 八、怎么验它真的在跑（最重要的一节）

这一节是我们刚交过学费的，放在后面但最该先看。

**读了代码说通了，不等于通了。** 执念池这一块，我们六月就写好、读过代码、确认逻辑没问题。三个月后拉账一看：零条执念。一次都没长出来过。

断在两处：

- 设计写的是「同一桩心事反复冒出来就沉淀成执念」，代码里「同一桩心事」写成了「一字不差的同一句话」。AI 每次措辞都不一样，永远不会一字不差。
- 念头淡化按心跳「拍」算。定参数时半小时一拍，后来心跳越来越密，一天一百多拍，一条闪念三小时就清空了。同一桩事隔半天再冒出来，早没了。

修法：合并看话题词重叠不看整句；淡化按时间算不按拍算，同一桩事被想起三次就成执念。修完拿三个月的真实心跳碎语回放一遍，长出四十多条，第一条在七月中。

**所以验收只有一种：拉账。** 每一处设计至少要能回答这三个问题：

1. 这条线过去一周有过几次真实的触发？账本里能数出来吗？
2. 触发之后数值真的动了吗？动的幅度对不对？
3. 有没有一条线三个月零账？有就是断的，不管代码看起来多对。

另一个坑：**测试灌进了真账本**。跑测试用了假时钟，一千多行假日期的记录写进了生产账本。数值没被顶爆，但账脏了。测试环境必须和真账本物理隔离，这条别等出事再加。
